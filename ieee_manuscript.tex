\begin{abstract}
Interplanetary communication networks are frequently disrupted by severe solar weather and planetary occultations, leading to significant packet loss and retransmission delays. This letter proposes the Electromagnetic Deep-space Transmission (EMDT) system, which integrates an Adaptive Intelligent Routing Controller (AIRC) for proactive path selection and an Adaptive Error Inference Layer (AEIL) for in-situ error recovery. Our simulation, validated against NASA DONKI solar superstorm data from May 2024, demonstrates a 70.8\% aggregate improvement in communication resilience and a Bit Error Rate (BER) of $4.22 \times 10^{-8}$ at 10 dB SNR. Furthermore, we demonstrate 99.3\% physical-layer authentication accuracy using SVD-based RF eigenfingerprinting. These results establish a robust foundation for next-generation deep-space telemetry.
\end{abstract}

\section{Introduction}
\IEEEPARstart{D}{eep-space} networks (DSN) face unique challenges due to extreme propagation delays and intermittent link availability. When solar flares occur, current reactive routing protocols detect failure only after significant data loss, triggering costly round-trip retransmissions \cite{rfc9171}. 

This letter introduces EMDT, a unified framework that switches from reactive detection to predictive mitigation. By combining topological foresight with local bit-error suppression, EMDT allows payloads to traverse degraded links that would typically be aborted, maintaining continuity across the solar system.

\section{Proposed System Architecture}
The EMDT system consists of three primary technical layers:

\subsection{AIRC Predictive Routing}
The Adaptive Intelligent Routing Controller (AIRC) utilizes a 15-minute predictive horizon to estimate Signal-to-Noise Ratio (SNR) degradation based on solar Kp-index forecasts. It reroutes payloads onto auxiliary planetary relays (e.g., Mars Reconnaissance Orbiter) before the main link enters its exclusion zone.

\subsection{AEIL Error Inference}
The Adaptive Error Inference Layer (AEIL) implements a Rate-1/2 LDPC Belief Propagation scheme. Unlike standard Forward Error Correction (FEC), AEIL is dynamically adjusted based on inferred channel noise, providing up to 6.5 dB of coding gain to recover corrupted telemetry in-situ \cite{gallager1962low}.

\subsection{RF Authentication}
To secure the node topology, we employ RF Eigenfingerprinting. Using Singular Value Decomposition (SVD), the system extracts unique hardware biases (phase noise and amplitude imbalance) to reject rogue spoofing nodes with high accuracy \cite{boussoufa2022rf}.
